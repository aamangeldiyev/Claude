# Детектирование печатей и текстовых меток в PDF

Полный проект для автоматического нахождения печатей и текстовых меток в PDF документах с использованием YOLOv8.

## 📁 Структура проекта

```
project/
├── input/              # PDF файлы для обработки
├── pages/              # Конвертированные страницы (PNG)
├── annotations/        # JSON файлы с разметкой
├── dataset/            # Датасет для обучения модели (YOLO формат)
├── output/             # Результаты обработки
├── temp_test/          # Временные файлы для тестирования
└── stamp_detection.ipynb  # Основной ноутбук
```

## 🚀 Быстрый старт

### 1. Подготовьте PDF файлы
Положите ваши 5 PDF файлов в папку `input/`

### 2. Запустите конвертирование
Cell 3: Конвертирует все PDF в изображения (PNG, 300 DPI)

### 3. Разметьте печати/метки вручную
Cell 5: Интерактивная разметка
- Откроется график с изображением
- Кликните и тащите мышь, чтобы создать бокс вокруг печати/метки
- Закройте график когда закончили
- Разметка сохранится в `annotations/`

**Инструкция по разметке:**
- Один клик + тащеденье = один бокс
- Зеленые боксы = уже размеченные
- Красные боксы = новые разметки
- Разметьте все видимые печати и метки на странице

### 4. Проверьте статистику (Cell 6)
Посмотрите сколько печатей размечено на каждой странице

### 5. Подготовьте данные (Cell 7)
Автоматически создает YOLO датасет (train/val split 80/20)

### 6. Обучите модель (Cell 8)
YOLOv8 nano - быстрое обучение (~15 минут на CPU)

### 7. Тестируйте на новых PDF (Cell 9-10)
Модель найдет печати на новых документах

## 🎯 Процесс разметки

**Что размечать:**
- ✅ Печати (овальные, круглые, прямоугольные)
- ✅ Текстовые метки (важные надписи, подписи)
- ✅ QR коды (если есть)

**Как размечать:**
1. Кликните в левый верхний угол печати
2. Тащите в правый нижний угол
3. Отпустите мышь
4. Повторите для всех печатей на странице
5. Закройте график

## 📊 Результаты

После обучения модель сохраняется в:
```
runs/detect/train/weights/best.pt
```

Используется для детектирования новых печатей с confidence > 0.4

## 💾 Форматы файлов

**Annotations (JSON):**
```json
{
  "image": "pages/file_page_000.png",
  "image_width": 2480,
  "image_height": 3508,
  "bboxes": [
    {
      "coords": [x1, y1, x2, y2],
      "width": 100,
      "height": 50
    }
  ]
}
```

**YOLO Labels (TXT):**
```
0 0.5 0.5 0.2 0.1
```
(class, center_x_norm, center_y_norm, width_norm, height_norm)

## 🔧 Параметры обучения

Редактируйте в Cell 8:
- `epochs`: Количество эпох (50 - хорошее значение)
- `imgsz`: Размер изображения (640 - стандарт)
- `batch`: Размер батча (8 - для малых данных)
- `patience`: Ранняя остановка (10 эпох без улучшения)

## 📈 Улучшение модели

1. **Больше данных** - добавьте больше PDF для разметки
2. **Лучшая разметка** - убедитесь что все печати размечены
3. **Аугментация** - YOLO автоматически применяет
4. **Больше эпох** - для лучшего качества (но медленнее)

## 🐛 Troubleshooting

**Проблема:** Не работает разметка
- Убедитесь что запустили Cell 3 (конвертирование PDF)
- Закройте график перед тем как запустить следующий

**Проблема:** Файлы не находятся
- Проверьте что PDF в папке `input/`
- Запустите Cell 2 (создание папок)

**Проблема:** Медленное обучение
- Используйте GPU (установите CUDA)
- Уменьшите размер батча (batch=4)
